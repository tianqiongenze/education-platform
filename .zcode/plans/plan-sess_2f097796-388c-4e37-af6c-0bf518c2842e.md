## 阶段二: SDD 补全 (D-206~D-208) — 3 并行 Agent

### Agent 1: OpenAPI contract-first 迁移 (D-206)
- 将 `generate-openapi-specs.sh` 改为 "校验" 而非 "生成": spec 文件作为 source-of-truth
- 为 9 个核心服务创建 contract-first OpenAPI spec 文件 (`docs/contracts/openapi/{service}-openapi.yaml`)
  - portal-bff, core-business, grading-service, order-platform, payment-platform, data-platform, knowledge-bff, knowledge-service, tenant-service
  - 从现有 `bff-openapi.json` + 代码 `@RestController` 注解提取, 转为手写 YAML (source-of-truth)
- 新增 `.spectral.yml` (Stoplight Spectral linter 配置), 规则集: `spectral:oas` + 自定义 (naming, versioning, security)
- 新增 `scripts/lint-openapi.sh` — 对所有 contract YAML 运行 spectral lint, CI 门禁
- `generate-openapi-specs.sh` 保留但重定位为 "drift detection" (运行时 spec vs contract spec diff)

### Agent 2: AsyncAPI spec 创建 (D-207)
- 为 4 个 Pulsar topic 创建 AsyncAPI 3.0 spec (`docs/contracts/asyncapi/`):
  - `ep-business-domain-events.yaml` (core-business: CoursePublished, CourseArchived, UserFrozen)
  - `grading-service-events.yaml` (AssignmentPublished, AssignmentClosed)
  - `knowledge-service-events.yaml` (DocumentParsed, DocumentFailed)
  - `tenant-service-events.yaml` (TenantActivated, TenantSuspended, TenantReactivated)
  - `order-service-events.yaml` (OrderPaid, OrderRefunded)
  - `senior-care-events.yaml` (CarePlanActivated, CarePlanCompleted, ElderActivated, ElderDischarged, HealthAbnormalDetected)
  - `boardgame-service-events.yaml` (RoomStarted, RoomFinished, MatchFinished)
  - `ep-cache-invalidate.yaml` (三语言缓存失效广播)
- 每个 spec 包含: topic, message payload schema (JSON Schema), 消费者/生产者列表
- 新增 `scripts/lint-asyncapi.sh` — 使用 @asyncapi/cli 校验

### Agent 3: 前端技术债修复 — ui-kit Taro 解耦 + Taro 构建 (D-208)
**ui-kit Taro 解耦** (影响 5 组件):
- 创建 `ui-kit/src/components/primitives/` — 平台无关基础组件 (View→div, Text→span, Image→img)
- 用 conditional import 模式: `ui-kit/src/platform/taro.ts` (Taro 环境) vs `ui-kit/src/platform/web.ts` (Web 环境)
- 修改 5 个组件 (Button, Loading, Empty, VideoPlayer, ErrorBoundary) 使用 platform adapter
- 移除 `peerDependencies: @tarojs/components` — 改为 `optionalDependencies`
- admin-web/knowledge-admin 不再需要 mock `@tarojs/components` (删除 App.test.tsx 中的 vi.mock)
- 确保 Taro 小程序端仍正常 (platform/taro.ts re-exports @tarojs/components)

**Taro 构建修复** (babel-preset-taro TS 解析):
- 检查 `@babel/core`、`@babel/preset-typescript`、`babel-preset-taro` 版本对齐
- Taro 4.0.9 + React 19 需确认 babel-preset-taro 4.0.9 支持 TS 5.x
- 若版本不兼容: 锁定 `@babel/core@7.24+`, `@babel/preset-typescript@7.24+`, 添加 `babel.config.js` 显式配置
- 验证 `knowledge-mp` build (至少 `pnpm --filter knowledge-mp build:weapp` dry-run 或 tsc check)
