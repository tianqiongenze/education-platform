# ep-common

Shared Python utilities for the education-platform services (D-110).

## Modules

- `ep_common.config` — environment variable loaders with defaults and validation.
- `ep_common.health` — standard health-check response factory.
- `ep_common.response` — unified success/error JSON response envelopes.
- `ep_common.logging` — structured JSON logging setup.

No third-party runtime dependencies; only the standard library is required.
