二分查找的左右边界有什么区别？
AI
左边界找第一个 ≥ target（lower_bound），右边界找最后一个 ≤ target（upper_bound-1）。
// 左边界 while(l<=r){ if(a[m]>=target) r=m-1; else l=m+1; } // 右边界 while(l<=r){ if(a[m]<=target) l=m+1; else r=m-1; }
