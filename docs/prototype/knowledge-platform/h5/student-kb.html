二分查找的左右边界有什么区别？
AI
二分查找的左边界用于找第一个 ≥ target 的位置（lower_bound），右边界用于找最后一个 ≤ target 的位置（upper_bound - 1）。核心区别在收缩区间的方向：
// 左边界: 找到 target 时收缩右边界 while(l<=r){ if(a[m]>=target) r=m-1; else l=m+1; } // 右边界: 找到 target 时收缩左边界 while(l<=r){ if(a[m]<=target) l=m+1; else r=m-1; }
📚 [1] 二分查找.pdf §3.2 📄 [2] 算法基础.docx §5.1
J
能举个例子吗？数组 [1,2,2,2,3] 找 2 的左右边界。
AI
数组 [1,2,2,2,3] 中找 2：
• 左边界（第一个 2）= 索引 1
• 右边界（最后一个 2）= 索引 3
所以 2 出现的次数 = 右边界 - 左边界 + 1 = 3 次。这就是用二分解决「元素出现次数」的经典技巧。
